# Local Air-Con Repairs

An air conditioning repair, installation, and maintenance website with service-area pages.

**Live website:** [https://local-air-con-repairs.co.za/](https://local-air-con-repairs.co.za/)

## Portfolio archive

`exports/published-pages.xml` is a sanitized WordPress export of published pages, including the page content and layout data needed to review the site’s work. It is a content archive rather than a complete, ready-to-deploy website.

## What is included

- Published WordPress pages and page layout metadata.
- Public page text, page slugs, and public SEO fields.

## What is excluded

- WordPress core, plugins, hosting configuration, and database credentials.
- User accounts, visitor comments, customer/order records, analytics data, and tracking identifiers.
- Hidden email recipients and other form delivery settings. Forms, shop functions, and other server integrations need to be configured separately on a WordPress installation.

Images referenced by page content remain hosted on the live website. Importing the WXR file requires WordPress; Elementor is needed to edit pages built with Elementor.
